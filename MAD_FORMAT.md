# The `.mad` Document Format

What a `.mad` document is, and what it should be. The spec was restructured for the
open-source launch (2026-10-25) into one chapter per file under [`docs/`](docs/),
with the normative content moved verbatim -- **the chapters are the spec now**; this
file is a pointer so the many references to `MAD_FORMAT.md` by name keep landing.
