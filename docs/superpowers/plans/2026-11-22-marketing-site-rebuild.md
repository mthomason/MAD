# Marketing Site Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `mthomason/mad.github.io` as a Jekyll site that preserves every navigable URL, adds the same five translations as the documentation site, and tells the current developer-first story for app 0.7.

**Architecture:** One Jekyll layout and include set replaces the hand-copied header, footer, analytics, consent banner, and language switcher on every page. English pages stay at the site root; `de/`, `es/`, `ja/`, `pt-br/`, and `zh/` mirror the five content pages. A shared `_data/versions.yml` drives every version and release link. GitHub Pages builds and serves the result from `main`.

**Tech Stack:** Jekyll 4 / GitHub Pages plugins (`jekyll-seo-tag`, `jekyll-sitemap`), Liquid, static HTML/CSS/JS, Python 3 for the link and cross-repo checks, Playwright for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-22-documentation-and-marketing-design.md` (Reports repository)

**Scope:** This is Plan 2 of 2. Plan 1 (the documentation site) is complete and merged. This plan covers `/Users/michael/Projects/mad.github.io` only; the Reports repository is used as a read-only fact source and check runner.

## Global Constraints

- **Repository and branch:** `mthomason/mad.github.io`, feature branch `site/jekyll-rebuild` off `main`; deliver through a PR against `main`.
- **Live site:** `https://mad.everydayapps.com`, GitHub Pages, Jekyll build from `main`.
- **Preserved navigable URLs:** `/`, `/contact.html`, `/mad-file-type.html`, `/privacy.html`, `/thanks.html`, `/404.html`, and the same five under each language directory. Source files `README.md`, `AGENTS.md`, `privacy.md`, and `mad-file-type.md` are not navigable URLs and are intentionally removed or excluded.
- **Languages:** directory `zh` / tag `zh-CN`; `ja` / `ja-JP`; `pt-br` / `pt-BR`; `de` / `de-DE`; `es` / `es-419`. English is the source and `x-default`.
- **Version truth:** app `0.7` for macOS and Windows; engine `9.0` revision `r4433`; release `v0.7.0`; iOS between releases and returning early 2027.
- **Privacy:** the English policy is authoritative. Each translation carries an "English original prevails" notice. `AGENTS.md` is updated to permit the translation.
- **Licensing:** no licence body or notice is translated; links point at the authoritative files.
- **Branding:** background `#ffffff`, primary `#0AA0D5`, accent `#DC2449`. Tabs for indentation in HTML, CSS, and configuration.
- **Developer-first, unsigned builds:** the desktop downloads are unsigned; say so and link the install guidance. The iOS App Store returns in early 2027.
- **No source Markdown in the output:** `README.md`, `AGENTS.md`, and every other `.md` source are excluded; the sitemap is generated by the plugin.
- **Local Docker test credentials** are intentionally public in the documentation; they are not part of this site.
- **GitHub Pages plugin whitelist:** only `jekyll-seo-tag` and `jekyll-sitemap` are needed.

## Review Focus

1. **A URL changes or a page 404s.** Expected: every existing navigable URL and every download link still resolves. Pinned by the built-site link checker in Tasks 1-12.
2. **Analytics or consent breaks, or shows English on a translated page.** Expected: one include, localized banner markup, no inline duplicate. Pinned by the consent/layout tests in Tasks 2-4.
3. **A translation is missing or drifts**, so the switcher falls back to the language home. Expected: five content pages in each language. Pinned by the page-parity check in Tasks 5-10 and 12.
4. **A version, release, Windows, or database fact is stale** or disagrees with the docs. Expected: app 0.7, engine 9.0 (r4433), release v0.7.0, Windows present, databases and localization correct. Pinned by the cross-repo fact check in Task 11.
5. **Internal source Markdown is published** — `README.md`, `AGENTS.md`, or a duplicated `.md`. Expected: zero `.md` files in `_site`. Pinned by the leak check in Tasks 3 and 12.
