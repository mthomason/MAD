# App Store 文案

_以下是我目前在 App Store 中使用的文案。_

## 推广文本

随时随地设计和共享自定义商业智能报表。连接 SQL Server 和 MySQL，构建查询，即刻导出报表。

## 描述

MAD Designer 是一款强大的移动商业智能工具，让您直接从企业数据中设计、查看和共享自定义报表。它面向 SQL Server 和 MySQL 数据库构建，帮助专业人士在 iPhone、iPad 和 Mac（专为 iPad 设计）上将原始数据转化为清晰、可执行的洞察。

借助 MAD Designer，您可以安全地连接 SQL Server 和 MySQL 数据库，设计包含多个表、连接、分组和筛选器的即席查询，并构建带有数据标签、图像、摘要和自定义格式的丰富报表。报表可以作为交互式 MAD 文档文件与同事共享，也可以导出为静态 PDF 文件，以便更广泛地分发。

内置示例报表，帮助您快速上手。无论您是业务分析师、数据专业人员还是决策者，MAD Designer 都能让您轻松创建所需的报表——随时随地。

## 新功能

本次发布让 MAD Designer 重返 App Store，带来更新的兼容性与性能改进。9.0 版本为使用 SQL Server 和 MySQL 数据库设计和共享报表提供了更流畅的体验。
